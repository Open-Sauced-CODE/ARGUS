## Recording & Rehearsal Checklist

1. **Resolution & Capture:** Record at 1080p (`1920x1080`, 30 or 60 fps) with OBS Studio or Windows Game Bar (`Win + G`) and a clear headset/mic.
2. **Pre-Stage Before Recording:**
   - Verify `http://ec2-13-201-224-53.ap-south-1.compute.amazonaws.com/downloads` loads cleanly and serves `ARGUS-Desktop-Setup-v2.0.0-win64.exe`.
   - Ensure Ollama is running (or let ARGUS Desktop auto-start `ollama serve`), with `Qwen3.5-4B.Q4_K_M.gguf` in `D:\ARGUS` auto-detected in Tab 1 so both **`Import as argus-m1-sft`**, **`Verify / Load argus-m1-sft`**, and **`Pull qwen3.5:4b`** complete cleanly in seconds without network stalls.
   - Keep a real Terraform folder/GitHub repo URL ready (plus the `argus-scanner` AWS CLI profile if demonstrating live AWS control-plane scan).
   - If testing Windows SmartScreen after fresh download, note **More info → Run anyway** (or pre-install once beforehand so launching `ARGUS Desktop` from the Start Menu is instant during the 2m 45s capture).
3. **Browser Zoom:** Set browser zoom to 100% or 110% so attack graph labels, MILP curves, and HCL diffs remain crisp and readable.
4. **Strict Time Limit:** Keep the final exported `.mp4` strictly under **2 minutes 50 seconds** (max hackathon cap: 3 minutes).
