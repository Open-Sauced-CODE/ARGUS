## Purpose (5 lines)

This brief asks you to train five SFT adapter variants (fold-0 through fold-4) and harvest OOF
(out-of-fold) completions from each one. The OOF harvest closes stop rule S4: today we have only
15 unseen-clean SFT clusters; we need 44 more to certify P(wrong | auto-applied) <= 5%. Nothing
here changes the production model (argus-m1-sft); fold adapters are intermediate artefacts only.
Once Shaurya ingests the OOF rows, the SFT gate-only certificate will cover the new unseen clusters.

> **Honest caveat:** Each fold adapter trains on ~80% of the 230 train inputs. It is NOT the
> production SFT checkpoint. The resulting certificate describes the cross-fit procedure, not the
> shipped argus-m1-sft. The certificate is used ONLY to answer Q2 (is SFT essentially never wrong
> on unseen inputs?); it does not retrain or replace any production artefact.

```python
# In Colab (or locally), prepare the fold-f training data:
# fold_f_keys = folds["folds"][str(f)]["input_keys"]  (from folds.json)
# Filter ml/train_m1/data/sft_train.jsonl to exclude rows whose input_key is in fold_f_keys.
# Write the filtered file as ml/train_m1/data/sft_train_fold{f}.jsonl

import json

with open("docs/phase6_shaurya/crossfit/folds.json", encoding="utf-8") as fh:
    folds_data = json.load(fh)

fold_f_keys = set(folds_data["folds"][str(f)]["input_keys"])

with open("ml/train_m1/data/sft_train.jsonl", encoding="utf-8") as fh:
    rows = [json.loads(line) for line in fh if line.strip()]

hold_out = [r for r in rows if r["input_key"] in fold_f_keys]
train_rows = [r for r in rows if r["input_key"] not in fold_f_keys]

assert len(train_rows) + len(hold_out) == 2507, f"Row count mismatch: {len(train_rows) + len(hold_out)}"

with open(f"ml/train_m1/data/sft_train_fold{f}.jsonl", "w", encoding="utf-8") as fh:
    for r in train_rows:
        fh.write(json.dumps(r, ensure_ascii=True) + "\n")

print(f"fold {f}: train {len(train_rows)} rows, excluded {len(hold_out)} rows (sum = {len(train_rows)+len(hold_out)})")
```
