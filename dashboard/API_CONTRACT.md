# ARGUS Dashboard Frontend API Contract

This document specifies the TypeScript contracts and API service interfaces powering the ARGUS Web Dashboard. All backend integrations in Phase 7 must conform to these contract shapes.

---

## 1. Top-Level Entity Contracts (`src/types/index.ts`)

### `iamNodes`
Represents an identity, permission, or asset entity in the AWS attack graph.

```typescript
export type NodeKind = 'user' | 'role' | 'key' | 'sg' | 'bucket' | 'stmt' | 'admin' | string;

export interface iamNodes {
  id: string;              // Unique ARN or synthetic ID
  label: string;           // Human-readable node label (e.g. "developer-raynor", "customer-data")
  kind: NodeKind;          // Restricted to verified backend kinds: user, role, key, sg, bucket, stmt, admin
  risk: number;            // Personalized PageRank risk score (0 - 100)
  isEntry?: boolean;       // Attacker entry point marker (e.g. developer-raynor)
  isCrownJewel?: boolean;  // High-value target asset (customer-data S3 bucket)
  x?: number;              // Deterministic 2D canvas coordinate X (0 - 1000)
  y?: number;              // Deterministic 2D canvas coordinate Y (0 - 500)
  details?: Record<string, any>;
}
```

### `iamEdges`
Represents a privilege, escalation, or access vector between nodes.

```typescript
export type EdgeType =
  | 'CAN_ESCALATE'
  | 'DIRECT_ADMIN'
  | 'CAN_ACCESS'
  | 'RULE_TO_SG'
  | 'USES_KEY'
  | 'CAN_ASSUME'
  | string;

export interface iamEdges {
  source: string;          // Source node ID
  target: string;          // Target node ID
  etype: EdgeType;         // Edge relationship kind
  p: number;               // Transition / attack probability (0.0 - 1.0)
  isAttackPath?: boolean;  // Belongs to the primary attack chain
  isInterdicted?: boolean; // Edge cut by Network Interdiction MILP
  residual?: boolean;      // Alternate residual path remaining after interdiction
}
```

### `iamFindings`
Security finding generated by CIS/DPDP audit rules, with M1 repair patch and M2 conformal confidence score.

```typescript
export type FindingStatus = 'APPROVED' | 'NEEDS_REVIEW' | 'ESCALATED' | 'APPLIED';

export interface iamFindings {
  finding_id: string;      // Format: F-b42cc0f7
  rule_id: string;         // e.g. "dpdp.rule6_public_exposure"
  title: string;           // Sentence-case human description
  resource_id: string;     // Tokenized reference (e.g. BUCKET_1)
  resource_type: string;   // AWSS3Bucket, AWSIAMRole, etc.
  severity: 'CRITICAL' | 'HIGH' | 'MEDIUM' | 'LOW';
  status: FindingStatus;
  confidence: number | 'n/a'; // M2 posterior estimate or 'n/a' for human escalations
  threshold: number;       // Auto-apply risk cutoff (0.95)
  certified: boolean;      // false = "Threshold not yet certified"
  reason: string;          // Human justification for review
  escalated: boolean;      // If true, bypassed M2 directly to review queue
  tier_used: 'T0' | 'T1' | 'T2' | 'T3';
  generator_model?: string;
  latency_ms?: number;
  cost?: number;           // Interdiction cost units (1: restrict_cidr, 2: remove_policy_statement)
  edges_covered?: string[];// Graph edge identifiers severed by this fix
  patch_ir?: {
    finding_id: string;
    resource_ref: string;
    ops: Array<{
      op: string;
      attr?: string;
      value?: any;
    }>;
    rationale_ref: string;
  };
  diff?: {
    before: string;
    after: string;
  };
  privacy_receipt_id?: string;
}
```

### `iamComp`
DPDP Act / CIS compliance rule readiness and violation status.

```typescript
export interface iamComp {
  rule_id: string;         // e.g. "dpdp.rule6_encryption"
  name: string;            // e.g. "Rule 6 Encryption"
  score_pct?: number;      // Compliance percentage (absent for Rule 15 visibility flag)
  failing_count?: number;  // Active non-compliant resources count
  review_count?: number;   // Flagged resources count (Rule 15)
  status: 'PASS' | 'WARNING' | 'FAIL' | 'FLAGGED';
  is_visibility_flag?: boolean; // Rule 15 Region is a visibility flag, never a failure
  category: string;
  description?: string;
}
```

### `iamRem`
Network-Interdiction optimization result under cost budget $K$.

```typescript
export interface iamRem {
  budget: number;          // 0 - 6, default 3
  baseline_likelihood: number; // 0.906 (modelled attack likelihood)
  residual_likelihood: number; // 0.586 at budget 3
  selected_findings: string[]; // ['F-b42cc0f7']
  edges_interdicted: Array<{ source: string; target: string }>;
  cost_spent: number;
  pareto_curve: Array<{
    budget: number;
    residual: number;
    naive_residual: number;
  }>;
}
```

## 2. Asynchronous API Endpoints (`src/api/index.ts`)

| Function | Signature | Description |
| :--- | :--- | :--- |
| `getOverview()` | `() => Promise<OverviewPayload>` | Complete aggregate payload for Overview screen (computed metrics, headline, graph summary, 4 seed review findings, compliance status, footer fields). |
| `getGraph()` | `() => Promise<GraphPayload>` | Complete attack graph with node coords, kinds, risk, and directed edges. |
| `getFindings()` | `() => Promise<iamFindings[]>` | All findings across the cloud environment. |
| `getFinding(id)`| `(id: string) => Promise<iamFindings \| null>` | Single finding detail by ID. |
| `getCompliance()` | `() => Promise<iamComp[]>` | List of DPDP Act readiness rules. |
| `getInterdiction(budget)` | `(budget?: number) => Promise<iamRem>` | Solves/returns MILP interdiction frontier for cost budget 0–6. |
| `getApprovals()`| `() => Promise<iamFindings[]>` | Returns findings awaiting human approval (count seeded to 9). |
| `approveFinding(id)` | `(id: string) => Promise<{ success: boolean; finding?: iamFindings }>` | Approves a finding and moves status to APPROVED. |
| `getReceipt(findingId)` | `(findingId: string) => Promise<PrivacyReceipt \| null>` | Returns cryptographic zero-leakage privacy receipt. |
