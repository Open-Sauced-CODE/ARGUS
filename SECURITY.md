# Security Policy

## Responsible Disclosure

ARGUS is an open-source research and engineering platform designed for cloud security analysis, attack graph simulation, and automated remediation. Because this platform interacts with cloud infrastructure configurations and policies, security is paramount.

---

## 1. Zero Credentials Policy

**No real cloud credentials, AWS secret keys, session tokens, or private customer data belong in this repository.**

* All test fixtures, mock graphs, and testbeds must use dummy identifiers (e.g., `123456789012`, `AKIAIOSFODNN7EXAMPLE`) or cryptographically pseudonymized tokens generated by the Privacy Airlock.
* If you discover any inadvertently committed credential, private key, or real cloud token in the git history, please report it immediately so it can be revoked and expunged.

---

## 2. Reporting a Vulnerability

If you identify a security vulnerability in the ARGUS codebase (including bypasses in the Privacy Airlock or policy evaluation logic), please report it responsibly:

* **Email**: Contact the repository maintainers directly or email `shaurya.khanna.0108@gmail.com` / `prabhavtiwari9@gmail.com` with the subject line `[ARGUS Security Vulnerability]`.
* **Details to Include**:
  * Description of the vulnerability and affected component.
  * Minimal reproducible proof-of-concept (PoC) or execution trace.
  * Potential impact assessment.
* Please allow up to 72 hours for an initial response before public disclosure.
